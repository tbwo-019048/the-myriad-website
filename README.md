# The Myriad

> **Production:** [the-myriad-website.vercel.app](https://the-myriad-website.vercel.app/) — this is the live prod site.

Next.js website and content studio for *The Myriad*. Supabase-backed content layer
with a protected `/admin` editor; falls back to bundled default content when
Supabase is not configured.

See [SUPABASE_SETUP.md](SUPABASE_SETUP.md) for database setup and creating the
first administrator.
